# 热门币种与每日涨跌榜

交易平台左侧新增「热门 / 涨跌榜」。点击任意币种可切换主图表，并沿用现有收藏和最近浏览功能。

- **热门**：OKX 当前 USDT 永续合约中，按近 24 小时估算 USDT 成交额排列前 20 名。估算方式为币本位成交量乘最新价，不是精确的逐笔成交金额，也不是 OKX App 的搜索人气榜。
- **涨幅榜 / 跌幅榜**：分别展示正涨幅、负跌幅前 10 名，没有符合方向的币种时显示空状态。
- **最近 24 小时**：以 OKX `open24h` 为基准。
- **今天**：以 OKX `sodUtc8` 为基准，从北京时间 00:00 至当前，尚未收盘。
- **历史日期**：可选择最近 7 个已结束自然日，以 `1D` 日线的收盘价相对开盘价计算，仅使用 `confirm=1` 的已收盘日线。日界线为 UTC+8。

数据来自 OKX 公共接口，无需 API Key：

- `/api/v5/market/tickers?instType=SWAP`
- `/api/v5/market/candles?instId=…&bar=1D&limit=8`

接口字段依据：[OKX 官方 API 文档](https://www.okx.com/docs-v5/en/)。

实时榜单复用现有 5 分钟行情缓存。首次打开面板会在后台逐个获取当前在市 USDT 合约的日线；币种较多时需要几分钟，期间明确展示进度及每日已覆盖数量。新上市币种可能没有完整的 7 天历史，已下架合约不在统计范围内。

历史日线加载只使用一个后台任务，复用公共请求限速，每次请求后额外等待 250ms。连续 5 个合约失败会暂停，5 分钟后有页面请求时重试。单个合约失败不会丢弃其他合约的结果。完成的缓存保存在本地数据库，正常缓存 6 小时，失败缓存 5 分钟；跨北京时间零点后重新获取。

前端加载历史期间每 5 秒读取进度，完成后每分钟读取。刷新按钮读取当前缓存，不绕过限速。断网时保留上次画面并标记可能过期，不用零涨跌伪装正常数据。

后端入口：`GET /api/market/rankings`。返回热门、24h、今天以及带进度和覆盖率的历史每日涨跌榜。

更新代码后重新启动后端并刷新网页。前端生产文件已构建至 `platform/frontend/dist`。
