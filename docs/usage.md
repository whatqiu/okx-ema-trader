# 简明使用说明

双击 `start-platform.bat` 打开网页平台。网页中的交易都是本地模拟交易，
不会向 OKX 提交订单。独立执行器 `python -m okx_ema_trader.executor`
才会向 OKX 模拟盘下单，两者使用不同的账户记录。

## 日常操作

1. 看顶部连接状态，等待行情和账户加载完成。
2. 手动交易：选择币种、方向、名义金额和杠杆，检查保证金和手续费后下单。
3. 自动交易：在「自动」页选择监控币种、每笔名义金额、杠杆和最大持仓数，然后启用。
4. 持仓卡会显示止损价；需要提前退出时点「市价平仓」。

「名义金额」是持仓的总价值，保证金约为名义金额除以杠杆。
网页自动交易使用固定名义金额，不会采用独立执行器的风险预算仓位。

## 止损与暂停

网页新开仓使用 `config/config.yaml` 中的 `trading.stop_loss_pct` 设置价格止损，
当前为 2%。这是本地程序每约 15 秒检查的止损，程序关闭或断网期间无法执行；
恢复后按当时可成交价格平仓，不能保证成交在止损价。旧持仓保留原设置。
OKX 执行器则在交易所提交附带止损的订单。

网页账户回撤或连续亏损达到阈值后，会平仓并暂停开仓；失败的平仓会继续重试。
熔断同时限制手动和自动开仓。检查原因后可点「解除熔断」。
账户回撤仍超限时会再次熔断，解除按钮不会抹掉损失。

超过 60 秒的行情会重新获取；拿不到有效行情时暂停新增风险，显示错误原因。
行情恢复后自动重新检查，不需要反复切换自动交易开关。

## 余额与历史记录

清理历史只删除明细，保留累计盈亏，不会改变余额。重置模拟账户则会清空交易记录、
累计盈亏和风控基准。旧版本已经删除且没有备份的盈亏明细无法自动重建。

OKX 执行器使用实际成交和手续费结算交易盈亏。成交记录缺失或有额外加仓时暂停对应交易，
等待记录补齐或人工核对；资金费反映在交易所权益中，不计入单笔连亏统计。

这些修复改善记账和执行可靠性，不代表策略盈利能力得到验证。

## 更新后生效

先停止正在运行的平台，再双击 `start-platform.bat` 启动，随后刷新浏览器。
启动脚本检测到旧进程占用端口时会直接退出，不会替换旧进程。
本仓库包含已构建的前端文件，日常更新不需要另外安装前端依赖。
独立 OKX 执行器也需要单独重启；其持久化熔断不会因重启而解除。
