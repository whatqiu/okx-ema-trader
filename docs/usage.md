# 简明使用说明

双击 `start-platform.bat` 打开网页平台。网页中的交易都是本地模拟交易，
不会向 OKX 提交订单。独立执行器 `python -m okx_ema_trader.executor`
才会向 OKX 模拟盘下单，两者使用不同的账户记录。

## 日常操作

1. 看顶部连接状态，等待行情和账户加载完成。
2. 手动交易：选择币种、方向、名义金额和杠杆，检查保证金和手续费后下单。
3. 自动交易：在「自动」页选择监控币种、每笔名义金额、杠杆和最大持仓数，然后启用。
4. 持仓卡会显示强平价和退出缓冲；需要提前退出时点「市价平仓」。

「名义金额」是持仓的总价值，保证金约为名义金额除以杠杆。
网页自动交易使用固定名义金额，不会采用独立执行器的风险预算仓位。

## 止损与暂停

当前两条路径都采用 `trading.exit_mode: liquidation`，不再设置固定 2% 价格止损，
也不因单仓浮亏达到某个比例而提前退出。`liquidation_buffer_pct: 3` 的含义是：
多仓 `(标记价 - 强平价) / 强平价 <= 3%`；空仓方向相反。
越过强平价时仍会尝试退出。

网页以简化强平价和行情价格估算，每约 15 秒检查；OKX 执行器读取交易所返回的
预估强平价和标记价，每约 5 秒检查，入场信号仍按 K 线周期计算。两者都依赖程序
在线运行；断网、跳空和成交延迟可能导致来不及退出，不能保证避免强平。

网页旧持仓上的固定止损字段会被忽略。OKX 执行器启动对账后，只撤销账本中记录的
旧固定保护单，并验证撤销结果；若仓位已接近强平价则先保留原保护，由风控平仓。
无法读取有效强平价或无法确认撤单时会暂停，不会假装迁移成功。
全仓账户的强平价会随账户变化，部分情况下交易所不返回该值，此时暂停新增风险。

风险预算仓位按预估退出距离计算，不再除以固定止损距离。20 倍杠杆、3% 缓冲下，
用较大的多仓预估不利波动约 2.15% 计算，1% 风险预算对应名义仓位约为权益的 46.5%。
这是仓位估算，不是全仓模式的实际亏损上限。

反向信号退出、账户回撤和连续亏损熔断仍然保留。网页账户级熔断会平仓并暂停开仓；
OKX 执行器的强平缓冲触发也会进入熔断，便于核对账户。失败的平仓会继续重试。
熔断同时限制手动和自动开仓。检查原因后可点「解除熔断」。
账户回撤仍超限时会再次熔断，解除按钮不会抹掉损失。

超过 60 秒的行情会重新获取；拿不到有效行情时暂停新增风险，显示错误原因。
行情恢复后自动重新检查，不需要反复切换自动交易开关。

## 余额与历史记录

清理历史只删除明细，保留累计盈亏，不会改变余额。重置模拟账户则会清空交易记录、
累计盈亏和风控基准。旧版本已经删除且没有备份的盈亏明细无法自动重建。

OKX 执行器使用实际成交和手续费结算交易盈亏。成交记录缺失或有额外加仓时暂停对应交易，
等待记录补齐或人工核对；资金费反映在交易所权益中，不计入单笔连亏统计。

这些修复改善记账和执行可靠性，不代表策略盈利能力得到验证。

## 更新后生效

先停止正在运行的平台，再双击 `start-platform.bat` 启动，随后刷新浏览器。
启动脚本检测到旧进程占用端口时会直接退出，不会替换旧进程。
本仓库包含已构建的前端文件，日常更新不需要另外安装前端依赖。
独立 OKX 执行器也需要单独重启；其持久化熔断不会因重启而解除。

2026-10-17 验证：249 项离线测试通过，前端构建通过。测试未向 OKX 下单。

回测按简化强平价计算触发边界，不能重建真实全仓账户的动态强平价。
历史的固定 2% 止损回测结果不代表当前退出规则。
